# Велес Агро — вариант 3

Самостоятельный локальный React + TypeScript проект. Реализованы главный экран, каталог, калькулятор стоимости, преимущества, производственный цикл, архивные сертификаты и контакты. Этапы и статус — в [PLAN.md](PLAN.md).

## Запуск

```sh
npm install
npm run dev
```

Превью: http://127.0.0.1:3003. Сборка: `npm run build`. Проверка сборки локально: `npm run preview`.

## Что работает

16 позиций из первого варианта, категории, поиск, температурные фильтры. Добавление и удаление позиций, ввод объёмов в кг, локальное сохранение и скачивание текстового списка. Начальный 1 кг — редактируемое значение интерфейса, не минимальная партия.

## Границы первого среза

Отправки менеджеру нет. Спецификации, контактная форма и интеграция — следующие этапы. Калькулятор использует введённые покупателем цены и не включает доставку. Контакты проверены на официальном сайте; документы явно отмечены как архивные. Источники: SOURCES.md. Данные каталога демонстрационные, требуют согласования.

## Источники

Изображения и локальные шрифты — `../weles-agro-demo-1/assets`. Каталог первого варианта указывает источником названий и фотографий https://www.weles-agro.ru/. Герой — концепция упаковки, а не утверждённая действующая упаковка. Лицензии шрифтов находятся в `public/assets/OFL-*.txt`.

Визуальное направление: ../weles-agro-demo-1. Структура React и идея подробного каталога: ../weles-agro-demo-2. Исходные проекты не изменяются.

## Интерактивный производственный цикл
Четыре этапа дополнены графиками: состав корма по фазам, масса и микроклимат по дням, сравнение охлаждения, температура при условной поставке. На графиках можно выбирать точки и управлять ползунками. Вкладки поддерживают стрелки, Home и End. Данные сценариев адаптированы из demo-2 и помечены как иллюстративные, см. SOURCES.md.

## Карта точек
В контактах добавлены Leaflet + OpenStreetMap, фильтры городов, интерактивные метки и карточки. Четыре адреса нанесены по координатам справочников. Гагарина без номера дома доступна в списке без метки. Промышленная, 5А обозначена как производство, а не подтверждённый магазин. Карта не считается полным реестром сети. Все источники перечислены в SOURCES.md; у карточек есть ссылки на источник и поиск в Яндекс Картах. При проблемах с загрузкой подложки адреса и ссылки остаются доступными.
